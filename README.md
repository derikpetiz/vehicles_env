# Dashboard de Vendas de Veículos

Este projeto é uma aplicação web desenvolvida em Python para análise exploratória de dados de anúncios de vendas de carros nos Estados Unidos.

## 🚀 Funcionalidades
- **Histograma interativo**: Exibe a distribuição da quilometragem (`odometer`) dos veículos.
- **Gráfico de Dispersão**: Permite analisar a relação entre o preço (`price`) e o odômetro.
- **Controles Interativos**: Interface com botões e caixas de seleção construídos via Streamlit.

## 🛠️ Tecnologias
- Python 3
- Pandas
- Plotly Express
- Streamlit
